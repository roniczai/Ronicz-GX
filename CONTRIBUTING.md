# Contributing

RONICZ GX is pre-prototype research. This repository welcomes corrections, tests, documented trade-offs, RTL experiments and reproducible measurements.

1. File an issue describing the engineering question and why it matters.
2. State assumptions and link primary sources. Do not imply a hypothesis was measured.
3. Keep experiments reproducible; include test commands and expected results.
4. Avoid proprietary vendor code, confidential board documents, copyrighted technical material, third-party firmware or restricted IP without permission.
5. Disclose conflicts and licensing restrictions.
6. Never post credentials, private supplier quotes, unpublished patent details or personal information.
7. Public performance claims must include hardware, driver, workload, precision, batch size, power measurement method and reproducible logs.

This repository is **not** taking orders or distributing a complete GPU.
