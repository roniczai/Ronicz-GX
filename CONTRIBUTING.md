# Contribute to RONICZ GX

This is early independent research in **consumer-accessible computing**. The project welcomes students, engineers, makers and creators.

We are seeking **specific, reproducible input** rather than claims of finished GPU performance:

- Vector/RTL correctness tests and reference algorithms.
- GPU scheduling and memory-system literature.
- FPGA implementation plans, resource and timing measurements.
- Windows / graphics driver feasibility information.
- Open compiler and rendering API experiments.
- User research about gaming, creation, rendering and local AI.
- Thermal, power, modular repair and ownership design studies.

## How to contribute

1. Open an issue with one well-defined engineering or user-access problem.
2. State current evidence and assumptions, and cite primary sources.
3. Submit a small reviewable pull request with tests, or a reproducible research note.
4. Disclose licenses, known limitations, benchmark setup and measurement method.
5. Don't copy proprietary GPU RTL, firmware, private design documents or unlicensed third-party source.

Every result must be labeled **hypothesis**, **simulation**, **prototype**, **measurement** or **commercial validation**.

Do not add fictional renderings presented as photos, invented benchmark results or claims that GPU silicon or the complete workstation already exists.
