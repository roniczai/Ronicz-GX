# Primary-source references for future engineering research

Research reference list assembled 9 November 2026. Listing a source is not an endorsement, partnership, IP license or claim that RONICZ GX meets any vendor's specifications.

- [NVIDIA GeForce RTX 5090 specification overview](https://www.nvidia.com/en-in/geforce/graphics-cards/50-series/rtx-5090/): competitor features and memory type as context, not an achievable parity claim.
- [NVIDIA DGX Spark hardware](https://docs.nvidia.com/dgx/dgx-spark/hardware.html): illustrates the alternative Arm/unified-memory approach. RONICZ GX Station proposes **separate system RAM and GPU VRAM**.
- [PCI-SIG](https://pcisig.com/): PCIe standards and compatibility reference.
- [Microsoft WDDM driver documentation](https://learn.microsoft.com/en-us/windows-hardware/drivers/display/): Windows GPU driver integration requirements.
- [Khronos Vulkan](https://www.vulkan.org/): open graphics and compute API ecosystem.
- [Blender Open Data](https://opendata.blender.org/): reproducible rendering benchmark methodology.
- [Vortex GPGPU](https://github.com/vortexgpgpu/vortex): independent academic GPU research example, subject to its own license.
- [Icarus Verilog](https://steveicarus.github.io/iverilog/): RTL simulation tool.
- [GitHub Actions](https://docs.github.com/en/actions): current public test runner.

No proprietary NVIDIA, Intel, AMD or other vendor GPU designs, firmware or SDKs are distributed in this repository.
