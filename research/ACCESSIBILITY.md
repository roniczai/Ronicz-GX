# Designing for accessible personal computing

**Goal:** investigate technical and ownership choices that could widen access to serious desktop graphics and compute power.

This document intentionally contains **no product budget, price, sales estimate or procurement promise**. Financial feasibility has not been established.

## Questions for users

- What do students and self-taught developers need locally that current devices cannot do?
- Which creative and 3D applications are truly blocked by dedicated-memory limits, and which are compute- or driver-limited?
- What makes an everyday desktop repairable, upgradeable and quieter?
- When does a computer become a better option than cloud rental for a small individual workload?
- Can a single general-purpose system genuinely support gaming, AI, creative work and ordinary productivity without sacrificing reliability?

## What can be investigated now

- Component standards and modularity.
- Driver availability and stability.
- Memory needs by reproducible application and model tasks.
- Power, cooling, acoustics and serviceability test plans.
- Open educational hardware experiments.
- Consumer interviews and transparent documentation.

## Future evidence

Demonstrated hardware, user testing and independent real-workload comparisons will be required before any accessibility claims become measurable product outcomes.
